## Slide 2: Context (15 seconds)

"The end users are home cooks, students, and families who want to plan meals efficiently. The problem is simple: people lose track of recipes, and compiling a grocery list from multiple recipes manually takes time and leads to mistakes. My solution is a web app where you save recipes with structured ingredients, and with one click, get a merged shopping list — plus AI tools to help structure cooking steps."

---

## Slide 3: Implementation (20 seconds)

"I built this with FastAPI on the backend, vanilla JavaScript on the frontend, and SQLite for storage. Version 1 had the core CRUD operations and search. In Version 2, I added a shopping list aggregator grouped by recipe with checkable items, difficulty ratings from 1 to 5 stars, cooking time tracking, smooth live search, dynamic tags, and AI-powered tools — including structured cooking steps, grammar checking, and unit correction. I addressed TA feedback by improving UI responsiveness, adding real-time validation, and documenting the API with Swagger."
